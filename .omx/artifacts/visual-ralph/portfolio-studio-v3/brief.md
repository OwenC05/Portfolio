# Portfolio visual reference v3 — The working table

Date: 2026-11-14. Stage: concept generation and visual review; awaiting approval of a reference. The existing interactive draft is preserved in `design/portfolio-draft`.

## Direction selected by the user

Expressive engineering studio: custom diagrams, tactile details, restrained motion. The current draft feels too basic and AI generated. The audience remains software engineering and applied AI hiring.

## Intended result

A recognisable personal portfolio that makes Owen's engineering and judgement tangible. Identity first, inspectable work second. A recruiter should find the three relevant projects in the first screen and understand the engineering contribution without inflated claims.

## Composition

- Compact navigation, then an oversized typographic treatment of **Owen Cheung**. A characterful serif paired with a plain grotesk; avoid the current generic slogan and repeated eyebrow/headline formula.
- An asymmetric working-table hero, combining a short personal introduction with a commissioned mechanical-key material study. Stone, chalk, graphite, and one oxidised-orange detail. This is an illustration of a personal interest, not a photograph of Owen's actual equipment.
- A compact, legible work index in the opening screen: Dissertation / Application Copilot / TypeForge. Work must not disappear beneath a huge decorative hero.
- Dissertation: a deep-graphite research spread with precise, readable experiment structure. Plain Qwen bypasses retrieval; the RAG condition adds custom TF-IDF context. Use no invented performance chart.
- Application Copilot: an inspection-sheet composition around evidence, recorded stages, and human review. Label illustrative material clearly. Mark the project in development.
- TypeForge: a spacious typographic interaction, connecting the physical key study to the browser product. Do not imply measured user improvement.
- A compact personal section and direct contact links. No fake availability, client logos, awards, counters, or generic service cards.

## Visual language

Warm stone `#E8E5DC`, chalk `#F8F6EF`, graphite `#242821`, oxidised orange `#C7482D`. The exact shades may be tuned for accessible contrast. Material depth comes from one genuine image asset, contact shadows, cropping, and restrained offsets, not a grain overlay or decorative gradient blobs. Mono is reserved for real technical data. Each project has a distinct composition rather than repeating cards.

Motion remains a later implementation decision: one deliberate keypress or assembly transition, no perpetual ambient movement. Reduced-motion presentation is still and complete.

## Content boundaries

- LNRS: deployed developer workflows using instructions, scripts, skills and context management. Do not represent this as ownership of a custom production autonomous agent backend.
- Dissertation: self-hosted Qwen inference on a university GPU server; custom TF-IDF RAG; reproducible exploratory benchmark. 20 questions, 40 primary outputs, one GPU are setup counts on a fictional teaching fixture. Not completed thesis findings, general accuracy, or an always-on service.
- Application Copilot: local-first evidence-based drafting workflow, durable jobs and recorded stages. Synthetic tests exercise workflow behaviour; full end-to-end recovery and semantic quality qualification remain milestones.
- TypeForge: a browser typing product with local storage, a Python ML benchmark, and a versioned model artifact. No claimed typing-speed or learning gains.
