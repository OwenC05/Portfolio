# Owen Cheung Portfolio

Portfolio website built with Next.js 14, TypeScript, and Tailwind CSS.

The immersive after-hours studio is being developed on [`feature/studio-v2-after-hours`](https://github.com/OwenC05/Portfolio/tree/feature/studio-v2-after-hours). Follow the [work log](design/studio-v2/work-log.md) for verified progress and outstanding work, and [CONTRIBUTING.md](CONTRIBUTING.md) for the development and review workflow. This branch is a work-in-progress checkpoint, not a completed release.

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- ESLint + Prettier

## Getting Started

```bash
npm ci
npm run dev
```
