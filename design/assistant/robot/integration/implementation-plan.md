No independent render loop or perpetual hover/bob/blink loop.

6. **G4a — assembly.** Root instantiates the hook once within Studio and wires controlled panel state, shared snapshot/selection, scene props, heading/return focus and history precedence. Confirm no robot request/import outside Studio; `/ask` stays its own route. Run integrated rapid-close/project-navigation failures before visual polishing.
