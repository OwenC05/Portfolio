# Apprentice verification matrix

15 November 2026. Planned checks, **all unrun for the robot**. This document does not turn previous assistant/Studio evidence into integration acceptance. R1–R10 refer to the [master plan](../../../../.omx/plans/studio-apprentice-robot.md); semantics refer to the [state contract](state-contract.md). Each row gives a reproducible setup/action and observable verdict. All ten master requirements have mapped checks; all 36 rows are testable (100% of this matrix), although R2/visual judgments require human review and several inputs are still pending. This is specification coverage, not test coverage or a pass rate.

U = focused unit/CPU behavioral check; B = real-browser observation; A = actual exported asset/profile check; V = independent Claude visual/interaction review; D = explicitly named physical-device or screen-reader session. CPU shims cannot satisfy B/V/D. Browser emulation cannot satisfy physical-device claims. No extra dependency or generic test framework is requested.
