16 November 2026. Read placement.md and ask-interface.md as design proposals, with these dispositions. This authorises reversible prototype work, not final placement or user acceptance of measured room fit.

- Start at root anchor [0.80,2.80,-0.20], yaw quaternion [0,-0.19612,0,0.98058], effective wrapper scale 1.6. Express this as the established 2 world-units/metre conversion times a provisional 0.8 character-size factor, applied once; do not change the room's unit convention or add its floor offset. Keep the enhanced HTML Ask entry immediately available in every Studio view, including WebGL failure, plus the existing /ask fallback. Root returns focus to the HTML entry when activation came from the canvas. P2's statement excluding character activation does not remove this requirement; Codex owns its picking implementation.
- Implement the proposed left-of-centre desktop sheet, phone bottom sheet and 0.32 assistant-only backdrop as prototype defaults. Existing project styling/backdrop stays intact. Root owns the one native dialog, active-panel arbitration, history, scroll and heading/return focus.
- Accept 'Search sources' and 'Waiting for the response to finish' as truthful generation-off copy. Keep published-source cautions and unsupported-question contact guidance. No generated-answer or fake-progress UI.
- Three-line passage previews are acceptable with an explicit accessible Show/Hide passage control revealing the full text. No returned hit or citation is dropped, reranked or truncated in state. Current selected key drives the matching row/chip/scene cue.
- Accept the proposed Studio-panel Cancel policy: invoke cancel, then focus the persistent Search sources button. Search and Cancel use correctly enforced aria-disabled states without removing their focus targets. This is not a change to /ask's separately recorded nonblocking focus behavior.
- No-match uses the character's own right mitten, toward the desktop sheet on the visitor's left. Asset author should preserve a visible empty-tray distinction; phones retain the same local gesture even though the sheet covers the scene.
- Tray emission is a fixed subdued decorative value across poses; runtime source cards/counts convey retrieval results. Marker selection may use one finite lift/outline but never delays clearing/replacement or creates decorative extra cards.
