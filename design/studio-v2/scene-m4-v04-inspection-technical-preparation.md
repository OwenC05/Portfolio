## Exported POSITION/NORMAL correspondence

Path: `scene-coordination/m4-v04-export-correspondence.py`.

```python
audit_export_correspondence(
    candidate_bytes, rows_bytes, witness_bytes, *,
    expected_candidate_sha256, expected_witness_sha256, expected_builder_sha256
) -> dict
```

This read-only API requires caller-supplied exact raw-export, measurement-witness and released-builder hashes. It does not derive trusted expected pins from the witness. `sourceScriptSha256` must equal the supplied executed-builder pin, `exportReadback.rawSha256` must equal the supplied raw pin, and both actual byte hashes must match. All inspection input pins, selected P14 pose, root-frozen rows and frozen-builder lineage must match. The checker pins its own guard dependency and records its own code hash. Hashes bind evidence; they do not prove that a claimed process really executed, so S/root must capture and review the actual execution provenance.

**Supported author witness:** `inspection.rows[row]` supplies helperVertices/helperFaces, meshVertices/meshPolygons/meshLoops, triangles, explicit unique `flippedPolygonIndices`, customNormals, the matching custom-normal winding count and the exact loop-order contract string. The author interim implementation asserts source polygon vertex-set correspondence for all 18 rows. No new witness field or changed geometry/export method was requested. Each reported winding reversal must independently agree with the actual exported triangle orientation; the witness cannot make contradictory triangles pass.

**Positions and frames:** helper vertices are Blender world metres with +Z up; raw glTF export_yup maps `(x,y,z)` to `(x,z,-y)`, a proper axis rotation. The checker rounds source coordinates once to IEEE binary32, then permutes/sign-flips axes. The GLB root and each M4 leaf must be identity-transformed, root-parented exactly once, with one uncompressed triangle primitive, matching row asset/material and FLOAT VEC3 POSITION/NORMAL. The runtime scale 2 and runtime Y offset 0.11 do not belong in these raw GLB attributes. Numeric signed zero is canonicalized to +0 only; no other position or normal epsilon exists. Quantised/compressed/morphed/skinned geometry, sparse accessors or nonidentity transforms fail rather than silently changing interpretation.

**Source-corner identity:** exact quantised position tuples locate possible source polygons, then each exported triangle must identify exactly one source polygon and its three original corners. The checker does not trust exported vertex numbering and permits UV/normal corner splits, vertex/triangle reordering and either valid quad diagonal. Per-polygon checks require n?2 triangles, exact oriented boundary coverage, paired opposite internal edges, noncrossing triangulation diagonals, nondegenerate consistently oriented projected triangles and complete source-face coverage. Ambiguous coincident polygons or float32-collapsed source corners fail closed rather than choosing a nearest point. Each row emits the complete exported-triangle/source-face/source-vertex/exported-vertex/winding map and its canonical digest. This supports Blender loop triangulation without assuming the source fan order.

**Normals and the practical limit:** the exact frozen source normal for that particular face/corner is multiplied by the witnessed winding sign, rounded to binary32 and transformed `(x,z,-y)`. Exported NORMAL must equal that tuple exactly. The test covers custom and automatic-normal rows; neither class is silently exempted. Finite components are required; a substituted component fails even when an angular diagnostic rounds to zero. Reversing a normal without corresponding witnessed face reversal fails.

The held builder calls `normals_split_custom_set` only on rows with authored N1 classes; other rows use Blender automatic normals. Blender may normalize/encode/read back custom normals differently from directly rounded source doubles, and automatic generated fans may differ from the helper field. The exact encoding/quantisation equivalence has NOT been established without the eventual export. Therefore this checker may return `positionAndTopologyExact=true` but `strictSourceNormalAgreement=false` for a geometrically reasonable real export. It reports mismatch occurrences, exact float32 words, corner locators, vector-length range and angular differences; these are diagnostics, not a tolerance allowance or a planar-only substitute for full correspondence. Such a result is a concrete fail-closed blocker for correspondence acceptance that root must disposition from actual evidence. No claim that Blender v5.2.41 necessarily preserves normal bits is made.

Exporter assumption is the exact proposal asset metadata: generator `Khronos glTF Blender I/O v5.2.41`, glTF version `2.0`. This generator string identifies the add-on, not a verified Blender executable version. The executable/add-on installation and precise numerical behavior remain later build provenance. Alternate exporter versions are not accepted merely because geometry looks similar.

Corner mapping proves only its declared POSITION/topology/strict NORMAL scope. It does not certify UV seams, all materials, textures, performance, visibility or art; transition and full structural checks remain necessary. The witness explicitly names the raw export.
